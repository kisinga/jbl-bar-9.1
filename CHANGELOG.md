# Changelog

## v0.1.0 — 2026-10-19

First public experimental release, preserving the exact owner-tested revision 5 device scripts. Includes persistent startup hook, indefinite standby waiting, guarded Smart-to-Standard selection, socket-descriptor correction, automatic build checks, logs and uninstall package.

Confirmed: new boot and delayed power-on on one supported Bar 9.1. Still open: repeated wakes, CEC/STR, other units/builds and long-term reliability. Initial installation needed one retry after unconfirmed long press. Release packaging/docs changed; device code did not.
